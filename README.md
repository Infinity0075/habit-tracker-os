# DisciplineCore

A modern Android app focused on self-discipline, habit tracking, daily wins, and personal growth.

## Features
- Habit tracking
- Discipline score
- Daily wins journal
- Streak tracking
- Focus-based productivity

Built using:
- Kotlin
- MVVM
- Room Database
- Material Design
