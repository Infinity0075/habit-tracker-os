# DisciplineCore 🚀

DisciplineCore is a modern Android productivity and self-discipline app designed to help users build consistency, track habits, and improve daily performance.

The app focuses not only on habit tracking but also on personal growth, accountability, and self-awareness.

---

## ✨ Features

- ✅ Habit Tracking
- 📈 Daily Discipline Score
- 🔥 Streak System
- 🏆 Daily Wins Journal
- 🌙 Morning & Night Reflection
- 📅 Schedule & Routine Tracking
- 🎯 Minimal & Clean UI
- 💾 Local Data Persistence using Room Database

---

## 🛠 Tech Stack

- Kotlin
- MVVM Architecture
- Room Database
- RecyclerView
- Material Design Components
- Android Jetpack Libraries

## 🧠 Inspiration

Most productivity apps focus only on tasks and checkboxes.

DisciplineCore is designed around identity-building, consistency, and self-discipline psychology.

The goal is to help users become more accountable to themselves and build long-term habits.
